## 背景（2026-09-21 实测，全部在真实用户路径 `whisper build -t c2` 上复现）

战役 O / O′ 修掉了「顶层」与「列表字面量」两种容器里的引号，但同一根因在
**其余五种容器**里原封不动。根因是同一个：

> `fuse-hof` 把「引号作值」展开成一对 token——定义 `[9, "__qN", body]` 与
> 引用 `[16, "__qN"]`。**只有顶层的定义**会被 `split-defs` 收走、发射成静态
> 函数 `W___qN`；落在任何**容器节点内部**的定义，都会走到 `compile-one`
> 的兜底分支（它没有 tag 9 分支），变成
> `#error whisper-cgen: unknown bare opcode`。

实测矩阵（VM 全部正确，c2 全部编不过）：

| 容器 | 程序 | VM | c2 |
|------|------|----|----|
| 顶层 | `{ 9 } call .` | 9 | ✅ 9（O 已修） |
| 列表字面量 | `[{ 9 }] 0 @nth call .` | 9 | ✅ 9（O′ 已修） |
| **条件分支** | `#t ?? { 9 } \| { 8 } ] call .` | 9 | ❌ |
| **循环体** | `2 { { 5 } drop 1 - } { dup 0 > } # .` | 0 | ❌ |
| **词定义体** | `: f { { 5 } drop 7 } ; f .` | 7 | ❌ |
| **引号体** | `{ { 5 } } call call .` | 5 | ❌ |
| **高阶词体** | `[1 2] { { 7 } drop 1 + } @map .` | `[2 3]` | ❌ |

对应的节点类型：条件 `[7,…]`、循环 `[8,…]`、定义 `[9,…]`、高阶融合体
`[249..254,…]`，以及引号体经 `[9,…]` 定义体间接落入。

## 设计约束（提前写明，避免事后合理化）

现有 `lift-list` / `lift-list-iter` 只认 `[6,…]` 一种容器。本战役要求把它
**一般化为「按字段递归」**：对容器节点 `[tag, f1, f2, …]`，凡是**列表**字段
就当作一条 token 流处理（先 `fuse-hof`，再划分定义/其余），定义上抬、节点
就地重建。`[9, name, body]` 的字段 1 是名字（字符串，非列表）自然被跳过。
判定「是不是容器」用 tag 区间：`6..9` 与 `249..254`。

### 实际采用的实现（符合预注册的"一条通用通路"约束）

把 O′ 那版只认列表的 `lift-list` / `lift-list-iter` 一般化成三个词：

- `part` / `part-iter`：一条 token 流 → `[defs, rest]`。先在本层 `fuse-hof`
  展开裸引号，再把 `[9,…]` 定义拣出来。状态 = `[tokens, rest, defs]`。
- `hs`：容器节点 → `defs… ++ [node']`。按 tag 区间分派：
  `6`(列表) / `7`,`8`(条件、循环) / `9`(词定义) / `249..254`(高阶融合体)；
  非容器原样包成单元素流返回，所以 `fuse-hof` 尾部不必先判种类。
- `hs1` / `hs2` / `hs9`：按"哪些字段是 token 流"分三种装配
  （@1；@1+@2；@2，`name` 字段是字符串自然跳过）。

`fuse-hof` 三处接上：容器下潜分支、**融合分支**（新造的 `[249..254, inner]`
也要过 `hs`）、**非融合分支**（新造的 `[9,"__qN",inner]` 也要过 `hs`——否则
`{ { 5 } }` 里层引号的定义还是留在定义体里）。后两处是初版遗漏，靠探针抓出来。

### 实施中踩到的坑（都写进代码注释了）

1. **`rot` 只转栈顶三件**。四件一组时最底下那件永远上不来，我据此写的重建
   序列全错。改用"读取时把源列表换回栈顶"的模式：每次取值 `dup … @nth` 后
   `swap`，取出的值沉到源下面，源始终可再取，最后 `drop` 源即得按读取顺序
   排好的序列。
2. **`dup N @nth` 是嵌套索引**：`1 @nth` 会消费掉上一个结果，
   `dup 1 @nth 1 @nth` 是"取第 1 项的第 1 项"而不是"取两次第 1 项"。
   我按后者写了一轮，多出一层索引。
3. **`concat-bc` 拼的是"列表的项"**，不是"把两个列表当一个"。
   拼 `ref ++ hsres` 时必须先 `1 PushList` 把 `[16,"__qN"]` 包成
   `[[16,"__qN"]]`，否则它会被摊成两个 token（正是 O′ 之前那个症状的变体）。
